# 拾影画报 · Photo Zine

把一张实拍照片编排成纸感剪贴画报：主图、细节摄影、纸片文字与手绘线条按照照片内容组合。

## 安装

将「拾影画报-Photo-Zine-Skill.zip」交给支持本地 skills 的 AI 助手，并发送：

> 请安装附件里的 photo-editorial 技能，并检查 SKILL.md、references/ 和 assets/ 是否完整。

这个 ZIP 内的技能文件夹叫 photo-editorial。需使用支持图片生成或编辑能力的工具；本包不包含模型服务、额度或 API 密钥。

## 开始使用

上传照片后说：

> 使用 $photo-editorial，把这张照片做成纸感剪贴画报，保留主体，从原图提取配色，加入与题材相符的手绘线条。

可以附带想要的标题、画幅或装饰密度。成品默认不添加演示标签、风格名称和工具水印。

## 精修示例

- 保留构图与小图大小，只让文字完整露出。
- 让装饰形成长短变化的三四组线条，保持纸感。
- 背景纸纹再轻一些，标题阴影再淡一些。

生成式编辑可能重绘原片细节。需要照片像素不变时，明确要求保留原始照片资产的分层排版。

## 包含内容

- SKILL.md：入口与工作规则。
- references/：构图、配色、装饰线条、提示词与检查方法。
- assets/：原创 AI 合成海景案例的视觉参考，供理解纸感风格，不是每次输出的固定背景。
- agents/openai.yaml：显示名称和调用示例。

技能由本次工作流编写，不含其他作者的 skill 源码。实拍测试图片的摄影来源另列，不装进技能包。
