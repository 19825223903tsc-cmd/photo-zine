# Photo Zine · 拾影画报

Turn a real photo into a tactile paper-collage editorial poster.

The skill adapts the main image, meaningful detail crops, palette, bold Chinese type and hand-drawn accents to the source photograph. Default output is a single 3:4 poster without tool labels or watermarks.

[Download the skill](../downloads/photo-editorial.zip) · [Chinese overview and examples](../README.md)

## Use

Extract the ZIP and install the complete `photo-editorial` folder in your AI tool's skills directory. The tool needs local skill access and image generation or editing capabilities; the skill does not include a model service or credits.

Upload a photo and ask:

> Use $photo-editorial to turn this photo into a tactile paper-collage poster. Preserve the subject, derive the palette from the source, and use hand-drawn accents that fit the scene.

You can specify the headline, aspect ratio, detail-crop size and decoration density.

## What the examples establish

Five real-photo cases cover a cat, breakfast, a rainy street, a jellyfish and a basketball hoop. Their layouts and palettes vary while the paper-collage character stays consistent. These are coordinator-reviewed examples, not an independent or cross-model evaluation.

Generative editing can redraw details; it does not guarantee pixel-identical photography. When exact preservation is required, use a layered layout that retains the source image asset. That route is described but was not tested in these examples.
