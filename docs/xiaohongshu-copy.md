# 小红书发布文案草稿

标题：给猫排了个版，它直接宣布不营业

这只猫的表情，配上「今天先不营业」——突然像替我说了句心里话。🤣

同一张照片，加上纸片字、局部特写和手绘线条，居然有了独立杂志封面的感觉。

于是又拿早餐、雨天街景、水母和篮筐试了一遍：早餐排出了慢生活，水母像在梦游，篮筐也有了「投个好心情」的劲儿。

相册里那些舍不得删、又不知道怎么发的照片，终于有了新玩法。

我把这套做法整理成了一个 skill：「拾影画报 / Photo Zine」。

它会根据照片挑颜色、安排主图和细节，再配上适合这个题材的纸感文字与线条。

安装后，上传照片，直接说：「用拾影画报，把这张照片做成纸感剪贴画报。」

Skill 包已经整理好了，需要支持 skills 和图片编辑的 AI 工具。

如果只能先做一张，你会选自家猫、旅行照，还是今天的早餐？
