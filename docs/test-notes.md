三个结果没有继续套蓝黄海景配色，主图与细节位置也不同，说明当前规则可以迁移到这些题材。但都仍属于同一纸片大字家族，不能据三张样例宣称覆盖所有摄影或获得平台流量。

## 仍有的限制

生成式编辑重描了毛发、面包纹理、部分街景细节，局部图不是原片的可验证精确裁切。雨天信号灯及小招牌的文字不得作为事实转录。原图保真排版需要单独输出保留原始图像文件的 HTML/SVG 等分层文件。本次测试没有执行或验证该路线。

背景及文字纸纹偏明显，适合当前选定的剪贴风。若后续追求更平整的印刷质感，应单独降低材质强度，不自动缩小细节图。

水母：横幅原片转为曲线撕边主体区，左下放大裙边纹理，蓝粉取色，漂浮方向的手绘线条。标题“漂浮／一会儿”可读，保留单只水母可辨的形态。

篮筐：主图斜切、右上篮筐连接与绳结细节，橙色纸底与浅蓝文字，装饰弧线呼应篮圈。标题“投个／好心情”可读，未新增球或运动员。
